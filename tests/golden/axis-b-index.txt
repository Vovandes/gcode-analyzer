== Шпаргалка для постпроцессора ==

  Строка O с номером (O0001) в строке 1. Символ % встречается 1 раз (строка 43), не в начале файла, последняя строка файла.

  --- 2. Формат кадра ---
  Нумерация N: не используется.

  Типичный порядок адресов в кадре (по средней позиции): T G D H Z S X Y B F M
  Самые частые последовательности слов в кадрах из двух и более слов:
      G Z  (6)
      G B  (2)
      G X  (2)
      G Y  (2)
      G Z F  (2)
      G H  (1)
      G X Y  (1)
      G X Y B  (1)

  Слова без пробела: 1 из 45 пар соседних слов. По видам:
      T+M: 1 (например `T1M6`)
  Остальные слова разделены одним пробелом.
  Регистр: только верхний (80 слов).
  Хвостовых пробелов нет.
  Концы строк: CRLF 0, LF 43; самая длинная строка 33 символов.

  Числа по адресам (знаков после запятой; целые значения с точкой `Z32.` или без `Z0`):
      B: слов 3, знаков после запятой до 0; целых с точкой 3 (`B0.`), без точки 0
      D: слов 1, знаков после запятой до 0; целых с точкой 0, без точки 1 (`D1`)
      F: слов 2, знаков после запятой до 0; целых с точкой 2 (`F300.`), без точки 0
      H: слов 3, знаков после запятой до 0; целых с точкой 0, без точки 3 (`H1`)
      S: слов 2, знаков после запятой до 0; целых с точкой 0, без точки 2 (`S4000`)
      X: слов 4, знаков после запятой до 0; целых с точкой 4 (`X0.`), без точки 0
      Y: слов 4, знаков после запятой до 0; целых с точкой 2 (`Y0.`), без точки 2 (`Y0`)
      Z: слов 10, знаков после запятой до 0; целых с точкой 8 (`Z50.`), без точки 2 (`Z0`)
  Нулевое значение оси: без точки 4 (`Y0`), с точкой 5 (`B0.`): запись нуля непоследовательна.
  Нули справа в дробной части: не пишутся (`1.5`, не `1.500`).
  Ноль перед точкой у чисел меньше 1: пишется (`0.5`).
  Знак `+` у положительных чисел: не пишется.

  Ведущие нули в кодах меньше 10:
      G: без нуля - G0 G1; с нулём - нет
      M: без нуля - M1 M3 M5 M6 M8 M9; с нулём - нет
      T: без нуля - T1; с нулём - нет
      H: без нуля - H0 H1; с нулём - нет
      D: без нуля - D1; с нулём - нет

  Дуги G2/G3 в программе не встречаются.

  --- 3. Модальность ---
  Кадров с перемещением: 14.
  Код движения (G0/G1/G2/G3): опущен при неизменном режиме в 2 из 14 кадрах; указан при смене режима 4 раз; повторён без смены режима 8 раз.
  Подача F в рабочих кадрах (4): опущена 2, указана при изменении 1, повторена с тем же значением 1.
  Координаты, не изменившиеся относительно текущей позиции (абсолютный режим): X повторено 0 из 4; Y повторено 1 из 2; Z повторено 1 из 8; B повторено 0 из 3;
  Вывод: неизменившиеся координаты частично повторяются, проверить правила вывода.
  Обороты S повторены с тем же значением: 1 из 2.
  M3/M4 повторены при уже включённом шпинделе: 0 из 2.
  Модальные G-коды, которые пишутся повторно при том же значении (повторов из всех вхождений):
      G90 2 из 4; G91 2 из 4; G43 1 из 2; G54 1 из 2;

  --- 4. Комментарии ---
  Всего комментариев: 7 (в скобках `( )`: 7, после `;`: 0).
  Отдельной строкой: 7, в одном кадре со словами: 0.

  Регистр букв: только верхний.
  Только ASCII (кириллица транслитерируется), символов вне ASCII нет.
  Знаки в комментариях, кроме букв и цифр: . : . Самый длинный комментарий: 31 символов.
