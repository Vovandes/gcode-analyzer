== Шпаргалка для постпроцессора ==
  Выведена из анализа программы, не из справочника: каждое утверждение относится к этому файлу.

  --- 1. Структура программы ---
  Начало программы (до первой смены инструмента), строки показаны как в файле:
      (Synthetic test only, not a KEDE program)
      G92 X0 Y0 Z0 B0
      G54 S1000 M3
  Строки O нет. Символ % не используется.

  Первая смена инструмента и подход (строки 4..5), значения заменены подстановками:
      T<t>M6
      G1 X<x> F<f>
  Остальных смен нет (инструмент один).

  Запись смены инструмента: T перед M6 (`T<t>M6`): 1.
  Предвыбор следующего инструмента: отдельный кадр `T<t>` после смены, 0 раз (смен 1, перед каждой сменой, кроме первой).

  Конец программы (после последнего рабочего хода, строка 6 и далее):
      G0 Y<y>
      G0 B<b>
      G4 X<x>
      M0
      M1
      M30

  --- 2. Формат кадра ---
  Нумерация N: не используется.

  Типичный порядок адресов в кадре (по средней позиции): G T S X Y Z B F M
  Самые частые последовательности слов в кадрах из двух и более слов:
      G B  (1)
      G S M  (1)
      G X  (1)
      G X F  (1)
      G X Y Z B  (1)
      G Y  (1)
      T M  (1)

  Слова без пробела: 1 из 12 пар соседних слов. По видам:
      T+M: 1 (например `T1M6`)
  Остальные слова разделены одним пробелом.
  Регистр: только верхний (22 слов).
  Хвостовых пробелов нет.
  Концы строк: CRLF 0, LF 11; самая длинная строка 41 символов.

  Числа по адресам (знаков после запятой; целые значения с точкой `Z32.` или без `Z0`):
      B: слов 2, знаков после запятой до 0; целых с точкой 0, без точки 2 (`B0`)
      F: слов 1, знаков после запятой до 0; целых с точкой 0, без точки 1 (`F600`)
      S: слов 1, знаков после запятой до 0; целых с точкой 0, без точки 1 (`S1000`)
      X: слов 3, знаков после запятой до 0; целых с точкой 0, без точки 3 (`X0`)
      Y: слов 2, знаков после запятой до 0; целых с точкой 0, без точки 2 (`Y0`)
      Z: слов 1, знаков после запятой до 0; целых с точкой 0, без точки 1 (`Z0`)
  Нулевое значение оси: без точки 4 (`B0`), с точкой 0.
  Нули справа в дробной части: не пишутся (`1.5`, не `1.500`).
  Ноль перед точкой у чисел меньше 1: пишется (`0.5`).
  Знак `+` у положительных чисел: не пишется.

  Ведущие нули в кодах меньше 10:
      G: без нуля - G0 G1 G4; с нулём - нет
      M: без нуля - M0 M1 M3 M6; с нулём - нет
      T: без нуля - T1; с нулём - нет

  Дуги G2/G3 в программе не встречаются.

  --- 3. Модальность ---
  Кадров с перемещением: 3.
  Код движения (G0/G1/G2/G3): опущен при неизменном режиме в 0 из 3 кадрах; указан при смене режима 2 раз; повторён без смены режима 1 раз.
  Подача F в рабочих кадрах (1): опущена 0, указана при изменении 1, повторена с тем же значением 0.
  Координаты, не изменившиеся относительно текущей позиции (абсолютный режим): X повторено 0 из 1; Y повторено 0 из 1; B повторено 0 из 1;
  Вывод: неизменившиеся координаты опускаются, пишутся только изменившиеся.
  Обороты S повторены с тем же значением: 0 из 1.
  M3/M4 повторены при уже включённом шпинделе: 0 из 1.
  Модальные G-коды (плоскость, G90/G91, G94/G95, СК и др.) повторно не пишутся.

  --- 4. Комментарии ---
  Всего комментариев: 1 (в скобках `( )`: 1, после `;`: 0).
  Отдельной строкой: 1, в одном кадре со словами: 0.
  Пробелы внутри скобок: `( текст )` - 0, `(текст)` - 1.
  Регистр букв: есть нижний (27 из 32).
  Только ASCII (кириллица транслитерируется), символов вне ASCII нет.
  Знаки в комментариях, кроме букв и цифр: , . Самый длинный комментарий: 39 символов.
  Виды комментариев по первому слову:
      Synthetic: 1, например `(Synthetic test only, not a KEDE program)`

  --- 5. Поворот оси B ---
  Кадров с B: 2, различных значений угла: 2, диапазон 0 .. 90.
  Как программируется (состав кадра с B):
      G00 B  (1), например `G0 B90`
      G92 X Y Z B  (1), например `G92 X0 Y0 Z0 B0`
  M-коды в кадре после поворота:
      M03 x1 - шпиндель по часовой

  --- 6. Машинно-специфичные коды ---
  Машинно-специфичных и неизвестных кодов нет.
