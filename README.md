# gcode-analyzer

Анализатор управляющих программ ЧПУ (Fanuc, фрезерование, 3 оси + индексная ось B) для разработки постпроцессоров (SprutCAM и др.).

По образцу рабочей программы строит текстовый отчёт: оценка времени обработки, список и порядок инструментов, рабочие СК, подачи и обороты, габариты траектории, статистика G/M-кодов, циклы сверления, предупреждения и **шпаргалка для постпроцессора** (структура программы, формат кадра, модальность, комментарии, поворот B).

> Статус: этапы 1-5 из [`docs/SPEC.md`](docs/SPEC.md) реализованы. Текущее состояние, результаты тестов и известные ограничения — в [`REPORT.md`](REPORT.md).

## Сборка

Требуется CMake ≥ 3.21 и компилятор с C++20 (GCC 11+, Clang 14+, MSVC 2022+).

```bash
cmake --preset debug && cmake --build --preset debug && ctest --preset debug   # Linux
cmake --preset msvc  && cmake --build --preset msvc-debug && ctest --preset msvc-debug   # Windows
```

## Использование

```bash
gcode-analyzer program.nc                    # отчёт в консоль
gcode-analyzer program.nc --out report.txt   # отчёт в файл (UTF-8)
gcode-analyzer program.nc --rapid 15000      # скорость G0 для оценки времени, мм/мин
gcode-analyzer --help | --version
```

Коды возврата: 0 успех, 1 ошибка ввода-вывода, 2 ошибка аргументов. Отчёт в UTF-8 на русском: для консоли Windows используйте `chcp 65001` или `--out`.

Профиль станка (значение машинно-специфичных кодов M15, M53 и т.п.) выбирается автоматически по комментарию `Generated for ...` в заголовке программы.

## Структура
- `docs/SPEC.md` — спецификация, факты о формате образцов, этапы
- `docs/PROMPT.md` — промпт для Claude Code
- `CLAUDE.md` — правила для Claude Code
- `samples/` — реальные УП-образцы (не изменять)
- `include/gca/`, `src/` — библиотека `gca_core` и CLI
- `tests/` — тесты Catch2; `tests/data/` синтетические программы (ось B, известное время, предупреждения); `tests/golden/` эталоны отчётов (чтобы осознанно обновить эталоны: создать пустой файл `tests/golden/UPDATE`, запустить тесты, удалить файл, проверить `git diff`)
